# Python - Everything is object

## Background Context
This project covers Python object concepts, including:
- Immutable vs Mutable objects
- References, Aliasing, and Identity (`id()`, `is`, `==`)
- Memory addresses in CPython

## Learning Objectives
- What is an object
- Difference between a class and an object/instance
- Difference between immutable and mutable objects
- Understanding references, assignment, and aliasing
- How Python passes variables to functions

## Requirements
- All answer files contain only one line.
- Interpreted/compiled on Ubuntu 20.04 LTS using `python3` (version 3.8.5).
